The first start downloads the model (about 35 GB) and loads it, which takes 15 to 20 minutes; later starts take a few.

Watch the engines become ready:
  kubectl -n {{ .Release.Namespace }} get pods -l app.kubernetes.io/instance={{ .Release.Name }} -w

What an engine is doing (waiting for the licence, downloading, loading):
  kubectl -n {{ .Release.Namespace }} logs {{ .Release.Name }}-engine-0 | grep level=

Your API key:
  kubectl -n {{ .Release.Namespace }} get secret {{ include "electron.keysSecret" . }} -o jsonpath='{.data.api-key}' | base64 -d; echo

The API, from inside the cluster:
  http://{{ .Release.Name }}-router.{{ .Release.Namespace }}.svc:{{ .Values.router.service.port }}/v1

{{- else if eq .Values.router.service.type "LoadBalancer" }}

The licence and the engines, as the router sees them:
  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ .Release.Name }}-router 8000:{{ .Values.router.service.port }} &
